About 3D NFT Studio

The best way to turn real objects into 3D NFTs

3D NFT Studio is a complete pipeline: capture a physical object with any phone scan app, upload the GLB, generate metadata, mint an ERC-721 on Polygon, view it in true WebXR AR and VR, then buy, sell and trade on the built-in marketplace.

How it works

  1. Scan – Polycam, Scaniverse, RealityScan, Kiri, etc. Export GLB.
  2. Upload – Drop the file. We normalize scale and prepare it for AR/VR.
  3. Describe – Name, category, rarity, optional AI description.
  4. Pin – Model + JSON metadata go to IPFS.
  5. Mint – One-click ERC-721 on Polygon (Amoy testnet or mainnet).
  6. Experience – Place in AR on real surfaces or explore in VR.
  7. Trade – List for sale, buy others, build a collection of digital twins.

Tech

  • Three.js + WebXR (hit-test AR + VR controllers)
  • ethers.js · Polygon · ERC-721
  • IPFS via Pinata
  • Static site – GitHub Pages

Go live (real minting)

  1. Free Pinata keys → js/config.js
  2. Deploy contracts/VRHologramNFT.sol on Remix (Polygon Amoy)
  3. Paste contract address into config
  4. Reload and mint for real

FAQ

Do I need a VR headset?

No. AR works on many Android phones and some iOS browsers. VR is optional for headsets. Desktop still lets you orbit and inspect every model.

What formats are supported?

GLB (preferred) and glTF. Almost every modern scan app exports these.

Is minting real?

Yes once you add Pinata keys and deploy the included contract. Without keys the full flow still works in demo mode.

Can I sell elsewhere?

Yes. The tokenURI points to IPFS metadata that includes the 3D model, so compatible marketplaces and wallets can display it.

Scanning Guide

Recommended apps

  • Polycam – excellent quality, easy export
  • Scaniverse – fast object scans
  • RealityScan – high fidelity
  • Kiri Engine – solid photogrammetry

Lighting

Soft, even light. Avoid harsh shadows and shiny reflections. Matte surfaces scan best.

Path

Slow full circle, then higher and lower arcs. Keep the whole object in frame. Overlap frames.

Export

GLB with textures. Aim under 20–25 MB for smooth mobile AR.
