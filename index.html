About VR 3D NFT Scanner

What is this?

A pure-frontend WebXR experience that lets anyone scan a real-world 3D object (via phone apps like Polycam or Scaniverse), turn the scan into a floating holographic digital twin, mint it as an ERC-721 NFT on Polygon, place it in true augmented reality on any surface, explore it in VR headsets, and buy / sell / trade it on a built-in marketplace.

The Duck Sample

The classic Khronos Duck model floats in the center of the gallery as a reference hologram. It demonstrates the exact visual style — gentle floating motion, soft emissive materials, platform glow, and AR placement behavior — that every scanned object receives.

How the pipeline works

  1. Capture – Use any photogrammetry app that exports GLB (Polycam, Scaniverse, RealityScan, etc.).
  2. Upload – Drop the file here. We normalize scale, add holographic materials, and prepare it for AR/VR.
  3. Describe – Name it and optionally generate a rich AI description.
  4. Pin to IPFS – Model + JSON metadata are pinned (Pinata when keys are set, otherwise demo mode).
  5. Mint – Call the VRHologramNFT smart contract on Polygon Amoy (or mainnet).
  6. Experience – Enter AR to place the hologram on real tables, floors, walls. Enter VR for immersive inspection.
  7. Trade – List on the marketplace, buy other creators’ scans, build a collection of real-world digital twins.

Tech stack

  • Three.js + WebXR (AR hit-testing + VR controllers)
  • ethers.js for wallet & contract interaction
  • IPFS via Pinata
  • OpenZeppelin-style ERC-721 (VRHologramNFT.sol)
  • Pure static frontend – deploys on GitHub Pages

Making it fully live

  1. Get free Pinata API keys and paste into js/config.js
  2. Deploy contracts/VRHologramNFT.sol on Remix (Polygon Amoy)
  3. Paste the contract address into config
  4. Reload and mint for real on-chain NFTs

FAQ

Do I need a headset?

No. AR works on many Android phones and some iOS browsers that support WebXR. VR works with Quest, Vision Pro (via browser), and other WebXR headsets. Desktop still lets you orbit and inspect the holograms.

What file formats are supported?

GLB (preferred) and glTF. Most modern scan apps export these directly.

Is this real on-chain minting?

Yes when you add your own Pinata keys and deploy the included contract. Without keys the app runs in full demo mode so you can still experience the entire flow.

Can I sell the NFTs elsewhere?

Yes. Once minted the tokenURI points to IPFS metadata that includes the 3D model. Compatible marketplaces and wallets that understand 3D NFTs can display them.

Why does the Duck look special?

It is the canonical sample that every new scan is styled after — floating animation, soft glow, platform, AR reticle placement. That is the “duck version” visual language of this app.

Complete Scanning Guide

Recommended apps

  • Polycam (iOS / Android) – excellent quality, easy export
  • Scaniverse (iOS / Android) – fast, good for objects
  • RealityScan (Epic) – high fidelity
  • Kiri Engine – photogrammetry alternative

Lighting & setup

Diffuse daylight or soft indoor light works best. Avoid harsh shadows and specular highlights. Place the object on a contrasting but non-patterned surface.

Motion path

Move in a slow circle, then higher and lower arcs. Overlap frames. Keep the object fully in frame. For complex shapes do a second pass from another angle.

Export settings

Choose GLB. Include textures if available. Aim for under 20–25 MB for comfortable mobile AR. You can always simplify later in Blender if needed.

After export

Return here, switch to Upload, drop the file, give it a memorable name, hit AI Generate for a rich description, upload to IPFS, and mint.
